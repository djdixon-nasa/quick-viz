About the data

Height above ground from the WERK lidar products, 2013-2023 (ORNL DAAC, doi:10.3334/ORNLDAAC/2523), at 3 m: the tallest 1 m pixel in each 3 x 3 block. The tiles are Cloud Optimized GeoTIFFs (COGs) on Hugging Face. There is no server: the map reads only the parts of the files it needs. The lidar tile outlines show which 3DEP tiles are on the NAS and which need downloading.
